# 실전 모의고사 조사와 적용 기준

조사일: 2026-11-03. 시험 자료를 복사하지 않고, 공개된 구성과 시간 규칙을 참고해 자체 문항과 안내문을 작성했다.

## 확인한 자료

- [IIBC 공식 시험 구성](https://www.iibc-global.org/english/toeic/test/speaking/about/format.html): 11문항, 다섯 유형, 문항별 준비 및 답변 시간. 5~10번의 질문 낭독 후 3초 대기를 명시한다.
- [ETS 공식 샘플](https://www.ets.org/pdfs/toeic/toeic-speaking-writing-sample-tests.pdf): 5~7번 공통 상황, 8~10번 자료 읽기, 10번 질문 2회, 11번 질문과 답변 방식.
- [토오미 모의고사 #28](https://www.youtube.com/watch?v=UgazFDbahuI): 화면과 음성의 구성 비교. 이 영상은 5~10번 질문 후 추가 안내가 있어 실제 대기 시간이 공식 3초보다 길다. 앱은 공식 3초 기준을 따른다.
- [토익스피킹 시뮬레이터](https://github.com/SunggaP/toeic-speaking-simulator): 사전 마이크 점검, 자동 진행, 시험 후 녹음 듣기 등의 사용 흐름 참고. 이 시뮬레이터는 5~10번 질문 텍스트를 숨기지만 토오미 영상에서는 5~7번 텍스트가 표시된다. 실제 시험 전체에 대한 단정은 피한다.
- [토스베어 모의고사](https://www.tossbear.com/toeic-speaking-mock-test): 전체 11문항 연속 녹음과 문항별 결과 확인 흐름 참고. AI 예상 점수는 해당 서비스 기능이며 이 앱에는 없다.

## 앱에 적용한 흐름

- 시작 전 마이크 권한과 첫 안내 음성을 준비한 뒤 전체 소개와 파트별 안내를 진행한다. 이후 음성은 시험 중 순서대로 미리 만든다. 생성이 늦으면 해당 안내 전에 기다린다.
- Q1~2는 지문을 읽기 전 45초, 답변 45초. Q3~4는 사진 준비 45초, 답변 30초.
- Q5~7은 공통 상황 안내 후 질문 음성 종료 → 3초 → 시작 신호 → 15/15/30초 녹음.
- Q8~10은 표를 45초 보고, 공통 상황과 질문을 듣는다. 10번은 두 번 듣고 3초 후 신호가 울린다. 답변은 15/15/30초다.
- Q11은 질문을 보고 듣고, 준비 45초 후 60초 답변한다. 모든 답변 후 다음 문제로 자동 진행한다.
- 5~7번 질문 텍스트 표시는 분석한 영상 기준이며, 8~10번은 표만 표시한다. 시험 화면의 지역·버전별 차이는 확인되지 않았다.

## 확인이 필요한 차이

- 앱에는 실제 시험의 음성이나 문제를 넣지 않았다. 비프와 상세 문구, 화면 배치는 ETS의 정확한 규격으로 검증된 값이 아니다.
- 마이크 사전 녹음·재생 점검, 시험 안내 화면의 정확한 절차, 시험 종료 직후 공식 오디오 확인 절차는 미구현이다.
- 음성 재생 종료부터 신호까지의 시간, 녹음 첫 음절과 비프 유입, 앱 중단과 이어폰 동작은 실제 iOS·Android 기기에서 확인해야 한다.
- AI 점수나 공식 성적은 제공하지 않는다. 시험 세트는 1회분이다.
