# 학습 경험과 UI 방향

작성일: 2026-11-03. 이 문서는 논의한 방향이다. 2026-11-04에 홈 한 문항, 파트별 탐색과 회차 목록을 구현했으며, 유료 정책은 아직 확정되지 않았다.

## 제품 방향

짧게 말하는 습관부터 시작해 필요한 파트를 연습하고, 준비가 되면 실전 모의고사를 풀 수 있게 한다. 사용자가 좋아한 라일락 코치 원본의 색감, 여백, 타이포그래피와 차분한 분위기를 유지한다.

## 세 가지 학습 경험

1. **오늘의 짧은 연습**: 한 문제를 듣고 제한 시간 안에 말하거나, 짧은 문장을 읽고 녹음한다. Part 3 질문, Part 5 의견 말하기, 짧은 지문 읽기 등을 후보로 한다. 녹음과 다시 듣기는 무료 경험으로 계획한다.
2. **파트별 집중 연습**: 지문 읽기, 사진 묘사, 질문 답변, 자료 활용, 의견 말하기 중 하나를 선택해 연습한다. 파트별 문제를 고르고, 향후 답변 내용·표현 및 발음 피드백을 제공할 수 있다.
3. **실전 모의고사**: 11문항을 시험과 유사한 흐름으로 진행하고, 이후 녹음과 문제별 복습을 제공한다. 중단한 시험은 이어하기를 우선 안내한다.

파트별 연습과 모의고사에도 일부 무료 체험을 제공하는 것을 고려한다. 추가 회차나 상세 AI 평가의 유료화 가능성이 있지만 가격, 범위, 무료 횟수와 결제 방식은 아직 정하지 않았다. 파트 연습 자체와 AI API 사용 비용은 별개로 판단한다.

## 화면 구성 제안

### 홈

현재의 인사말과 라일락 카드 형태를 유지하되, 카드에서 한 문항을 쉽게 시작하도록 한다. 질문 예시와 연습 유형, 실제 측정한 예상 시간, AI 평가 없이 녹음과 다시 듣기가 가능하다는 점을 표시한다.

카드 아래에는 `짧은 문장 읽기`, `의견 말하기` 같은 다른 짧은 연습으로 이동하는 선택지와 `파트별로 연습하기`, `실전 모의고사 풀기` 진입점을 둔다. 오늘의 추천 문제는 고정 또는 순환 방식 중 콘텐츠 운영 계획에 맞춰 결정한다.

### 파트별 연습

파트가 모의고사 화면 하단에만 보이지 않도록 별도의 탐색 영역을 제공한다. Part 번호와 함께 이해하기 쉬운 이름을 강조하고 문제 수와 실제 측정한 예상 시간을 보여준다.

- Part 1: 지문 읽기
- Part 2: 사진 묘사
- Part 3: 질문에 답하기
- Part 4: 자료를 보고 답하기
- Part 5: 의견 말하기

파트를 선택하면 문제 선택과 연습 시작으로 이어진다. 기존 문제 및 세션 엔진을 활용하되, 제공 범위는 추후 결정한다.

### 모의고사

회차별 카드에 11문항, 실제 측정한 예상 시간과 진행 상태를 표시한다. 중단된 회차가 있다면 `이어서 풀기`를 눈에 띄게 배치하고, 이어하기와 처음부터 시작의 차이를 설명한다.

### 하단 탐색

`학습 | 시험 연습 | 기록` 세 탭을 제안한다. `시험 연습` 안에 파트별 연습과 모의고사를 구분해 배치하며, 홈에서도 각각 바로 이동한다. 명칭과 실제 탐색 편의성은 사용성 확인 후 확정한다.

### 결과와 기록

무료 짧은 연습 결과는 `녹음 듣기 → 다시 말하기`를 중심으로 한다. AI 평가가 있는 경우에만 내용·표현·발음 피드백을 추가한다. 아직 제공하지 않는 점수나 그래프는 표시하지 않는다. 기존 회차 중심 기록, 녹음 비교, 문제 저장 및 삭제 기능은 유지한다.

## AI 평가와 비용

- 답변 텍스트의 문법·내용 분석과 실제 음성의 발음·억양·강세 평가는 다른 기능이다.
- 텍스트 분석용 로컬 모델과 발음 평가 API 조합을 검토할 수 있다. 발음 평가 API를 사용한다면 녹음 전송 안내와 동의, 보안, 단가와 사용량 한도를 먼저 설계한다.
- 공식 ETS 점수나 발음 평가 정확도를 검증하기 전에는 공식 채점처럼 표시하지 않는다.
- 유료 도입 시 시작 전에 무료 범위, AI 평가 포함 여부와 가격을 명확하게 알린다.

## 다음 순서

1. 홈의 한 문항 시작 경험과 진입 경로를 설계한다.
2. 파트별 연습과 회차 선택 화면을 분리한다.
3. 무료 결과 화면과 향후 AI 평가 결과 화면을 설계한다.
4. 실제 기기로 사용성을 확인하고 무료 체험 및 결제 범위를 결정한다.
5. 별도 실험으로 음성 평가 품질과 호출당 비용을 확인한다.

상세 전사·피드백 검토는 `AI_FEEDBACK_REVIEW.md`를 참고한다.

## 구현 현황 (2026-11-04)

- 홈에서 Q5 한 문항, 짧은 지문, 의견 말하기로 진입할 수 있다. 홈의 추천 질문은 현재 고정이다.
- 시험 연습 탭과 파트별 화면, 회차 목록을 분리했다. 파트별로 각 회차의 문항 또는 전체 파트를 선택할 수 있다.
- 중단된 모의고사는 회차 목록 상단에 표시하며, 회차를 열어 이어하기를 선택한다.
- 한 문항 연습 결과는 녹음을 바로 보여준다. 유료화·AI 평가·실측 기반 예상 시간은 아직 제공하지 않는다.
- 이 변경의 실제 iOS·Android 화면과 음성 흐름은 실기기 확인이 필요하다.

## 콘텐츠 현황 (2026-11-04)

- 모의고사와 별도로 파트별 연습 20문항씩 총 100문항을 제공한다. 각 문항은 개별 실행과 녹음, 예시 답변, 북마크와 다시 풀기를 지원한다.
- 사진 묘사는 새 사진 20장, 자료 활용은 서로 다른 자료 20개로 구성했다. 문제와 예시 답변에 대한 외부 감수 및 실기기 검증은 남아 있다.
