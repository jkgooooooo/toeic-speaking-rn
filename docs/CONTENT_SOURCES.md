- 모의고사 01~03의 지문, 상황, 질문과 예시 답변은 이 프로젝트를 위해 작성한 학습용 콘텐츠다. ETS 문제나 공식 답안이라고 표시하지 않는다.
- `mock-library.png`, `mock-park.png`, `mock-bakery.png`, `mock-market.png`, `mock-meeting.png`, `mock-station.png`는 이 프로젝트의 사진 묘사 연습을 위해 AI로 생성했다.
- 각 사진의 묘사 예시는 생성된 화면을 보고 작성했다. 시험 문항의 자연스러움과 예시 답변의 품질은 출시 전에 별도로 검토한다.
- 시험 구조와 시간의 근거는 `MOCK_EXAM_RESEARCH.md`에 기록했다. 다른 영상이나 시험의 이미지·음원·문장 원본을 복사하지 않았다.
- Supertonic 모델·글꼴의 라이선스와 모든 자산의 배포 고지는 `RELEASE_CHECKLIST.md`에 따라 최종 확인한다.

## 자체 검토 기록 (2026-11-03)

- 3개 회차의 영어 질문과 예시를 읽고 사진 문항 6개의 등장인물·행동을 이미지와 대조했다. 8~10번 예시의 시간·장소·진행자는 각 회차의 일정표와 일치한다.
- 예시는 여러 가능한 답변 중 하나이며, 읽기 문항은 지문을 읽는 연습이므로 지문을 예시로 제공한다.
- 이는 내부 검토이며 영어 교육 전문가의 감수, 실제 수험자의 이해도 검증 및 공식 문항과의 동일성 검증을 의미하지 않는다. 출시 전 외부 감수가 필요하다.

## 파트별 연습 콘텐츠 (2026-11-04)

- 모의고사와 별도로 파트별 20문항씩 총 100문항을 작성했다. Part 2는 AI 생성 사진 20장, Part 4는 별도 자료 20개를 사용한다.
