# 출시 전 확인

현재 구현은 개발용이며 스토어 출시를 확인한 빌드가 아니다.

## 실제 기기

- iPhone과 Android 실기기에서 짧은 연습과 11문항 모의고사를 끝까지 진행한다.
- 첫 음절, 안내 종료부터 준비 시간, 비프와 녹음 시작·종료, 재생 품질을 확인한다.
- 마이크 권한 거부, 전화·백그라운드 중단, 저장 공간 부족, 앱 재시작 및 기록 삭제를 확인한다. 시험 중 일시정지, 다른 앱 전환, 강제 종료 후 이어하기와 처음부터 다시 시작도 확인한다.
- iOS 음성 모델 최초 다운로드, 중단·재시도, 두 목소리의 첫 생성 시간과 오프라인 재사용을 확인한다. Android는 시스템 음성을 사용한다.
- 다양한 화면 크기, 글자 크기, 다크 모드와 스크린리더를 확인한다.

## 배포 설정

- 앱 이름, 아이콘, 스플래시, 고유한 iOS 번들 ID와 Android 패키지명을 확정한다. 현재 ID는 개발용이다.
- Apple과 Google 개발자 계정, 서명, 버전, 스토어 설명과 스크린샷을 준비한다.
- 실제 처리 방식에 맞는 개인정보 처리방침과 문의처를 마련하고 스토어 개인정보 항목을 작성한다. 녹음과 기록은 기기에 저장되며 앱 삭제 시 사라질 수 있다. 음성 모델 다운로드에는 외부 서버 연결이 필요하다.
- Supertonic 코드와 모델, 글꼴, 이미지 등 포함 자산의 라이선스와 고지 의무, 상표 사용을 최종 확인한다. 공식 시험 콘텐츠나 ETS 제휴로 오인되지 않도록 안내를 정한다.
- 릴리스 빌드를 생성해 TestFlight와 Google Play 내부 테스트를 거친다.

## 알려진 범위

- 오리지널 모의고사는 3회분이다. 각 회차의 사진과 학습용 예시 답변은 자체 제작·생성했으며 학습 적합성 및 라이선스 고지를 최종 검토해야 한다.
- iOS Supertonic은 모델을 내려받고 안내 음성을 처음 생성하는 동안 시간이 걸린다. 음성 캐시는 기기에서 삭제될 수 있어 필요하면 다시 생성한다.
- 자동 채점, 클라우드 백업과 기기 간 동기화는 제공하지 않는다.
