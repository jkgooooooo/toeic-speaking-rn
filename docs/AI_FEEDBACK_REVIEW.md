# 답변 전사와 피드백 검토

검토일: 2026-11-03. 아직 앱에 전사나 AI 채점 기능을 연결하지 않았다.

## 제안 순서

1. 저장된 짧은 영어 답변을 글자로 바꾸는 기능을 한 문항에 적용하고, 사용자가 녹음과 전사 결과를 대조해 수정할 수 있게 한다.
2. 전사 오류와 답변 길이를 확인한 뒤, 사용자가 요청했을 때만 질문과 전사문을 바탕으로 구체적인 표현 개선 제안을 제공한다. 원본 발음을 듣지 않은 텍스트 분석으로 발음 점수를 매기지 않는다.
3. 여러 사람의 동의받은 녹음으로 억양, 배경 소음, 짧은 답변, 무응답을 확인한다. 실제 시험 점수와의 관계가 검증되기 전에는 공식 점수나 합격 가능성을 표시하지 않는다.

## 전사 방식

- iOS 기기 내 인식: 외부 전송 없이 처리할 가능성이 있으나 언어와 기기에 따라 사용 가능 여부가 다르다. `supportsOnDeviceRecognition`을 확인하고 기기 내 처리를 강제해야 한다. Android는 별도 구현과 기기별 확인이 필요하다. [Apple 문서](https://developer.apple.com/documentation/speech/sfspeechrecognizer/supportsondevicerecognition)
- 자체 기기 내 모델: 인터넷 없이 처리할 수 있지만 모델 용량, 단말 속도, 발열과 네이티브 모듈 유지보수를 검토해야 한다. 기존 Supertonic은 읽어주는 TTS 모델이므로 전사 모델과 별도다.
- 서버 전사: 구현 후보로 OpenAI 파일 전사 API가 있다. 사용자가 선택한 녹음이 서버와 제공업체로 전송되므로 명시적으로 알리고 동의를 받아야 한다. 앱에 API 키를 넣지 않고 서버에서 관리한다. OpenAI는 녹음 파일 전사에 `gpt-transcribe`를 안내한다. [전사 가이드](https://developers.openai.com/api/docs/guides/speech-to-text)

## 비용 예시

OpenAI 공식 가격표의 `gpt-transcribe` 예상가는 **음성 1분당 $0.0045**다. 단순히 1,000명이 각 10분을 전사한다고 가정하면 전사 비용은 약 $45다. 실제 청구는 사용량 및 가격에 따라 달라지고, 텍스트 피드백 모델, 서버, 저장 및 통신 비용은 별도다. 구현 전에 가격을 다시 확인한다. [가격표](https://developers.openai.com/api/docs/pricing)

## 결정 전 확인

- 한국인 영어 학습자의 실제 녹음으로 기기 내 방식과 서버 방식의 정확도·처리 시간·비용을 비교한다.
- 녹음 전송 및 보관 기간, 삭제 방법, 제공업체의 데이터 처리 조건과 사용자의 동의를 설계한다.
- 접근 권한 및 오류 시 재시도와 삭제 정책을 정한다. 기능을 도입하기 전 개인정보 처리방침과 스토어 고지도 준비한다.
